## 📝 Cómo usar este archivo

**Desde MÓVIL:**
- Edita directamente en GitHub (click en ✏️)
- Agrega notas de cosas que quieres que haga el PC
- Ejemplo:
  ```
  TODO PC: Cuando estés en casa, implementa el login con email
  BUG: El chat de tareas no muestra mensajes en tiempo real
  IDEA: Agregar filtros en la página de agentes
  ```

**Desde PC:**
- Lee las notas del móvil
- Implementa lo que pida
- Actualiza con lo que completaste
- Ejemplo:
  ```
  ✅ DONE: Implementé login con email
  ✅ FIXED: Chat ahora actualiza en tiempo real
  ```
